# CompTIA A+ Study Guide for Beginners

A beginner-friendly introduction to preparing for the CompTIA A+ certification. This guide covers core study areas, practical preparation tips, and original practice questions.

> **Exam-version note:** Before studying, check CompTIA's official A+ certification page and download the objectives for the exam version you plan to take. Exam codes and objectives can change.

## 1. Understand the Two Exams

CompTIA A+ certification requires passing two exams: Core 1 and Core 2. Check the current official objectives for the exact topics and requirements.

### Core 1: Hardware and Connectivity

Study areas commonly include:
- Mobile devices and computer components
- CPUs, RAM, storage, motherboards, and power supplies
- Networking fundamentals, Wi-Fi, routers, and common connection problems
- Virtualization and cloud-computing concepts
- Hardware and network troubleshooting

### Core 2: Operating Systems and Security

Study areas commonly include:
- Operating-system features, settings, and utilities
- Installing, configuring, and troubleshooting software
- Security fundamentals, authentication, and common threats
- Malware prevention and basic incident response
- Operational procedures, documentation, safety, and professionalism

## 2. Build a Practical Study Routine

1. Download the official exam objectives and use them as your checklist.
2. Divide the objectives into small topics and study one topic at a time.
3. Practise hands-on tasks, such as identifying hardware, using operating-system tools, and diagnosing simple network issues.
4. Answer practice questions after each topic.
5. Review every incorrect answer and write down why the correct answer is right.
6. Revisit weak topics and test yourself again before booking an exam.

## 3. Original Practice Questions

These questions are for learning and are not actual CompTIA exam questions.

### Question 1: Computer Memory

Which component temporarily stores data and instructions that a computer is actively using?

A. SSD  
B. RAM  
C. Power supply  
D. Network interface card

<details>
<summary>Show answer and explanation</summary>

**Correct answer: B. RAM**

RAM provides temporary working memory for active programs and data. Its contents are generally lost when power is turned off.

</details>

### Question 2: Networking

A computer connects to a Wi-Fi network but cannot open websites. What is a useful first step?

A. Replace the CPU immediately  
B. Check whether other devices can access the internet and verify the computer's network configuration  
C. Format the hard drive  
D. Replace the monitor

<details>
<summary>Show answer and explanation</summary>

**Correct answer: B.**

Checking other devices and the computer's network settings helps narrow down whether the issue affects one device or the wider network.

</details>

### Question 3: Security

Which practice provides the strongest protection against password reuse across multiple accounts?

A. Use the same memorable password everywhere  
B. Write passwords on a shared desk  
C. Use unique passwords and a reputable password manager  
D. Disable account security settings

<details>
<summary>Show answer and explanation</summary>

**Correct answer: C.**

Unique passwords reduce the risk that one compromised account will expose other accounts. A password manager can help create and store them securely.

</details>
