## 🧠 Practice Question: IPv4 Subnetting

**Question:** A computer has the IPv4 address `192.168.1.70/26`. Which network does it belong to?

- A. `192.168.1.0/26`
- B. `192.168.1.64/26`
- C. `192.168.1.128/26`
- D. `192.168.1.192/26`

<details>
<summary>Click here to reveal the answer and explanation</summary>

**Correct answer: B — `192.168.1.64/26`**

A `/26` prefix uses the subnet mask `255.255.255.192`. Each subnet contains 64 addresses.

| Network address | Address range |
|---|---|
| `192.168.1.0/26` | 0–63 |
| `192.168.1.64/26` | 64–127 |
| `192.168.1.128/26` | 128–191 |
| `192.168.1.192/26` | 192–255 |

The address `.70` falls within the 64–127 range, so its network address is `192.168.1.64/26`.

</details>
